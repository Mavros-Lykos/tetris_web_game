# Tetris Web

A responsive, dependency-free Tetris game built with semantic HTML, modern CSS, and vanilla JavaScript.

## Features

- Standard 10 x 20 playfield with seven tetrominoes
- Clockwise and counter-clockwise rotation
- Collision detection, ghost piece, line clearing, scoring, levels, and speed increases
- Game-over detection and restart flow
- Keyboard and touch controls
- No build step, libraries, frameworks, or external assets

## Run locally

Open `index.html` in a modern browser. A local server is optional because the game has no server-side dependencies.

```text
index.html
styles.css
script.js
```

## Controls

| Input | Action |
| --- | --- |
| Left / Right | Move piece |
| Up | Rotate clockwise |
| Down | Rotate counter-clockwise |
| Space | Hard drop |
| P | Pause |
| Touch buttons | Move, rotate, or drop on mobile |
