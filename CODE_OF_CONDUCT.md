# Code of Conduct

## Our standard

We want this project to be a welcoming place for people with different backgrounds and experience levels. Be respectful, constructive, and considerate in issues, reviews, and pull requests.

## Expected behavior

- Use inclusive language.
- Explain disagreements with evidence and kindness.
- Accept feedback and help others learn.
- Focus on the work rather than the person.

Unacceptable behavior includes harassment, personal attacks, discrimination, and sharing private information without permission.

## Enforcement

Report serious or repeated problems to the project maintainers. Maintainers may remove comments, close discussions, or restrict participation when needed to keep the project healthy.
